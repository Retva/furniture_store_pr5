# Схема базы данных «МебельДом»

Коллекции создаются миграцией `pb_migrations/1732010000_init_collections.js`
(при `./pocketbase serve` или `migrate up`). Ниже — описание полей для отчёта
и ручной проверки в админке.

Поля `id`, `created` и `updated` PocketBase добавляет сам.

Связи:

| Тип | Где |
| --- | --- |
| один к одному | `customers` ↔ `discount_cards` |
| один ко многим | `manufacturers` → `products`, `customers` → `orders`, `products` → `orders` |
| многие ко многим | `products` ↔ `categories`, `products` ↔ `materials`, `manufacturers` ↔ `materials` |

## discount_cards — карты скидок (1:1 с покупателем)

| Поле | Тип | Настройки |
| --- | --- | --- |
| customer | Relation → customers | обязательное, одна запись, уникальное |
| number | Plain text | обязательное, уникальное |
| discount_percent | Number | обязательное, 1–50 |
| issued_at | Date | обязательное |

Отдельная коллекция нужна, чтобы явно показать связь один к одному и хранить
свойства карты. При оформлении заказа хук `pb_hooks/orders.pb.js` читает процент
скидки и считает `total`.

## orders — заказы

| Поле | Тип | Настройки |
| --- | --- | --- |
| customer | Relation → customers | обязательное |
| product | Relation → products | обязательное |
| user | Relation → users | кто оформил (для «Мои заказы») |
| quantity | Number | обязательное, целое ≥ 1 |
| total | Number | считается хуком с учётом скидки |
| cancelled_at | Date | пусто = активен |

Хук при создании: проверка остатка (иначе 409), скидка по карте, списание `stock`.

## Правила доступа

Миграция `1732010001_role_rules.js` закрывает запись по ролям. Смотреть каталог
могут авторизованные; менять — manager/admin; пользователей — admin; заказы
видны менеджерам/админам и владельцу записи.

Если seed отвечает 403 — либо заливайте под суперпользователем (так делает
`seed.mjs`), либо временно откатите ролевую миграцию.
